## 🚀 Getting Started & Setup Instructions

### 1. Database Setup
1. Open **MongoDB Compass** and create a new database named `clinical_trials`.
2. Import the JSON files from the `/01_database/` folder into their respective collections:
   * `patients`
   * `clinical_trials`
   * `interventions`
   * `adverse_events`
